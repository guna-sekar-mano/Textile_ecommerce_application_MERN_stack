# Textile_ecommerce_application_MERN_stack

A full-stack Textile Ecommerce Web Application built using the MERN Stack (MongoDB, Express.js, React.js, Node.js).
This platform allows users to browse textile products, add them to cart, and place orders, while administrators can manage products, orders, and users.

# 🚀 Tech Stack

**Frontend**

React.js

HTML5

CSS3 / Tailwind

Axios

**Backend**

Node.js

Express.js

**Database**

MongoDB (MongoDB Atlas / Local)

**Other Tools**

JWT Authentication

REST API

Git & GitHub
